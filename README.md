MIDNIGHT VAULT is an original top-down heist game that runs offline in a desktop browser from static files: move with WASD or the arrow keys, slip through four hand-designed vault floors, and fill your sack with cash bags, gems and gold. Guards patrol with vision cones, security cameras sweep the rooms and laser tripwires blink across the doorways — all of them feed one alarm meter, and a full meter (or the vault doors sealing at zero time) busts the job. A heavy sack slows you down, so bank your haul at the getaway van, hit each floor's quota, and finish with a clean getaway and a grade for the night's work.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network requests: the game is the plain files under `game/`, and all of its sound is synthesised live with WebAudio.
